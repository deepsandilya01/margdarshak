## 2. Node.js Gateway to FastAPI Contract Breakdown

In `primary-server/src/services/chat.service.js`:
```javascript
// Lines 28-39
const fastApiUrl = process.env.FASTAPI_URL || "http://localhost:8001";
let fastApiResponse;

try {
  const response = await axios.post(`${fastApiUrl}/chat`, {
    sessionId,
    message: message.trim(),
    language,
  });
  fastApiResponse = response.data;
} catch (error) {
  console.error("FastAPI Error:", error.message);
  const errorMsg = await messageRepository.createMessage({
    sessionId,
    role: "assistant",
    content: "I'm sorry, I am currently experiencing technical difficulties processing your request.",
    status: "error",
  });
  return { error: true, message: errorMsg };
}
```

### Contract Forensic Findings:
1. **No Timeout:** The `axios.post` call does not provide a `timeout` configuration. If an external service hangs, the Node worker remains blocked indefinitely.
2. **No Retries:** No retry mechanism (e.g. exponential backoff) is implemented.
3. **Connection Failure Behavior:** Since no server listens on port 8001, every request results in `ECONNREFUSED`. Node creates an assistant message with `status: "error"` in MongoDB, and `chat.controller.js` responds with HTTP 500 (`AI service unavailable`).
4. **Missing Context Argument:** In `BIS_SATHI_FINAL_API_JSON_AI_SERVICE_GUIDE.pdf`, the contract specifies sending an optional `context: { standardId: "..." }` payload. `chat.service.js` does not forward context.

## 3. Analysis of `ai-microservice/RAG/` Scripts

### 3.1 `1_ingestion_pipeline.py` (404 Lines)
- **Purpose:** Ingestion pipeline for PDFs into ChromaDB.
- **Implementation:**
  - Uses `DirectoryLoader(path=BASE_DIR, glob="*.pdf", loader_cls=PyPDFLoader)`.
  - Splits text via `RecursiveCharacterTextSplitter(chunk_size=3000, chunk_overlap=200)`.
  - Generates embeddings using `sentence-transformers/all-MiniLM-L6-v2`.
  - Persists vectors to directory `chroma_db/`.
- **Execution Test:**
  - Running `python 1_ingestion_pipeline.py` immediately raises:
    ```
    FileNotFoundError: No PDF files found in 'D:\Deep\bis\BIS-SATHI-SIH-26107\ai-microservice\RAG'. Please add your PDF documents.
    ```
  - **Verdict:** Code exists, but no source documents have been provided.

### 3.2 `2_retrievel_pipeline.py` (40 Lines)
- **Purpose:** Test vector similarity query against ChromaDB.
- **Implementation:**
  - Loads ChromaDB from `chroma_db/`.
  - Executes hardcoded query: `"AES Laboratories (P) Ltd Noida OSL"`.
  - Prints top 5 retrieved documents.
- **Execution Test:**
  - Fails if `chroma_db/` has not been generated by `1_ingestion_pipeline.py`.

### 3.3 `3_answer_generation.py` (223 Lines)
- **Purpose:** Standalone terminal Q&A generation.
- **Implementation:**
  - Uses `query = input("\nAsk your question: ")` for interactive terminal input.
  - Combines vector retrieval with regex matching for standard numbers (`IS \d+`).
  - Formulates prompt restricting answer generation to retrieved context only.
  - Invokes `ChatGoogleGenerativeAI(model="gemini-3.6-flash", temperature=0)`.
  - Prints output to standard stdout.
- **Execution Test:**
  - Cannot be called via HTTP or inter-process communication by Node.js.
  - Requires Google Gemini API key (`GOOGLE_API_KEY`) in `.env`.
